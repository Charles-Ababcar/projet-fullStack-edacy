# 📚 Book Management App

Une application de gestion de livres construite avec **React**, **NestJS**, **Tailwind CSS**, **Mantine UI** et **Redux Toolkit**.

## 🛠️ Technologies utilisées

- **Frontend** : React + Vite
- **UI Frameworks** : Tailwind CSS + Mantine UI
- **State Management** : Redux Toolkit (RTK) avec RTK Query
- **Backend** : NestJS
- **Base de données** : (MySQL)
- **API** : RESTful avec NestJS
